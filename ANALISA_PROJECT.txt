1. RINGKASAN SINGKAT
--------------------------------------------------------------------------------
Project ini adalah Sistem Informasi Manajemen Perpustakaan berbasis web yang
dibangun dengan Laravel Framework. Fitur utamanya meliputi manajemen buku,
kategori, anggota, peminjaman, pengembalian dengan perhitungan denda,
laporan PDF, dan autentikasi pengguna dengan peran (admin & member).

================================================================================

--------------------------------------------------------------------------------
| Komponen        | Versi / Detail             | Keterangan                            |
|-----------------|----------------------------|---------------------------------------|

3. ALGORITMA YANG DIGUNAKAN DAN LETAKNYA
--------------------------------------------------------------------------------

A. Pencarian & Filter Buku (Search & Filter)
   - File: app/Http/Controllers/BukuController.php (baris 16-30)
   - Algoritma: Query builder dengan klausa LIKE pada kolom judul, kode_buku,
     dan pengarang, serta filter berdasarkan kategori_id. Hasil diurutkan
     terbaru (latest()) dan dibagi halaman (paginate(10)).
   - File tambahan: app/Http/Controllers/MemberBukuController.php (baris 16-22)
     - Pencarian buku untuk member dengan logika serupa, paginate 8 per halaman.

B. Manajemen Stok Buku (Decrement/Increment)
   - File: app/Http/Controllers/PeminjamanController.php (baris 71-73)
     - Saat peminjaman, stok dikurangi 1 ($buku->stok--).
   - File: app/Http/Controllers/PengembalianController.php (baris 46-51)
     - Saat pengembalian, stok ditambah 1 ($buku->stok += 1).
   - File: app/Http/Controllers/MemberBukuController.php (baris 50-51)
     - Peminjaman member juga mengurangi stok.
   - Validasi: Jika stok <= 0, peminjaman ditolak dengan pesan "Stok Buku Habis".

C. Perhitungan Denda Keterlambatan
   - File: app/Http/Controllers/PengembalianController.php (baris 25-38)
   - Algoritma:
     1. Bandingkan tanggal hari ini (Carbon::now()) dengan tanggal jatuh tempo
        (tanggal_kembali).
     2. Jika hari ini > jatuh tempo, hitung selisih hari dengan diffInDays().
     3. Denda = terlambat x Rp1.000.
     4. Simpan ke field denda pada tabel peminjaman dan ubah status menjadi
        "Dikembalikan".

D. Autentikasi & Hashing Password
   - File: app/Http/Controllers/RegisterController.php (baris 57, 99)
     - Hash::make($request->password) untuk menyimpan password ter-encrypt
       (bcrypt).
   - File: app/Http/Controllers/LoginController.php (baris 36-42)
     - Auth::attempt(['email' => ..., 'password' => ...]) untuk verifikasi
       login.
   - File: app/Models/User.php (baris 48-51)
     - casts mengatur password sebagai 'hashed'.

E. Otorisasi Berbasis Peran (Role-Based Access)
   - File: app/Http/Middleware/CheckRole.php (baris 13-14)
   - Algoritma: Membandingkan auth()->user()->role dengan role yang diharapkan.
     Jika tidak cocok, abort(403) (forbidden).
   - Catatan: Dalam User.php tidak ada field 'role' di $fillable, hanya 'jenis'.
     Middleware CheckRole merujuk ke $user->role yang kemungkinan belum
     terdefinisi — ini bisa menjadi potensi bug.

F. Verifikasi NPM (Member)
   - File: app/Http/Controllers/MemberController.php (baris 19-39)
   - Algoritma: Membandingkan input NPM dengan Auth::user()->npm. Jika cocok,
     set session 'npm_verified = true' agar member dapat mengakses dashboard.

G. Statistik Dashboard & Grafik
   - File: app/Http/Controllers/DashboardController.php
   - Algoritma: Loop 12 bulan (for $i = 1; $i <= 12; $i++) untuk menghitung
     jumlah peminjaman per bulan menggunakan
     whereMonth('tanggal_pinjam', $i)->count(), lalu dikirim ke view untuk
     ditampilkan sebagai grafik.

H. Export Laporan PDF
   - File: app/Http/Controllers/LaporanController.php (baris 17-24)
   - Algoritma: Mengambil semua data peminjaman dengan relasi user dan buku,
     lalu merender view Blade ke PDF menggunakan barryvdh/laravel-dompdf dan
     mengunduhnya sebagai 'laporan-peminjaman.pdf'.

I. Model Reservasi (Catatan Anomali)
   - File: app/Models/Reservasi.php
   - Masalah: File ini bukan berisi model Eloquent biasa, melainkan kode yang
     mirip controller (memanggil view() dan auth() di dalam model). Ini adalah
     kesalahan penulisan/kode mati yang seharusnya dipindah ke Controller atau
     diperbaiki agar hanya berisi relasi model.
